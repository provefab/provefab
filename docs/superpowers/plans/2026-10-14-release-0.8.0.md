- Le contrôleur exécute les pushes, signatures, publications et déploiement déjà autorisés. Les agents implémenteurs ne publient rien.
- Les secrets restent dans leurs stores existants. Ne jamais imprimer de token ou copier de credentials dans les artefacts.
